# Результаты лабораторной работы 1

Шаблон для заполнения после самостоятельного выполнения ноутбука `notebooks/lab1_mushroom.ipynb`.

## Эксперимент

- Датасет: Mushroom, OpenML ID 24, версия 1
- Seed: 42; отложенная выборка: 20%, стратификация по class
- Редкость odor: доля строго меньше 10% в обучающей выборке
- Конвейер: RareOdorCounter → ColumnTransformer → LogisticRegression
- Подбор C: [0.1, 1.0, 10.0], 5 фолдов, выбор по ROC-AUC
- Дата запуска и окружение: **заполнить после выполнения ноутбука**
- SHA-256 данных, размеры train/test и пропуски: **из run_metadata.json**
- Редкие символы и их частоты: **из odor_frequencies.csv**

## Воспроизводимость

Опишите, какие меры обеспечивают воспроизводимость эксперимента:

- Фиксированные версии зависимостей в requirements.txt
- Random state = 42 для всех стохастических операций
- SHA-256 проверка исходных данных
- DVC для версионирования данных и модели
- Фиксация разбиений train/test перед обучением
- Пересчёт частот редких символов внутри каждого CV-фолда

## Предотвращение утечки данных

Объясните, как исключена утечка информации из test:

- Разбиение выполняется до обучения любых преобразований
- Test не участвует в расчёте частот, импутации, масштабировании, кодировании
- GridSearchCV работает только с train
- Частоты редких символов обучаются заново в каждом фолде CV
- Положительный класс 'p' для метрик определён корректно
