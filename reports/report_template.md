# Результаты лабораторной работы 1

Шаблон для заполнения после самостоятельного запуска. Здесь нет заранее
рассчитанных метрик или утверждений об успешном обучении.

## Эксперимент

- Датасет: Mushroom, OpenML ID 24, версия 1.
- Seed: 42; отложенная выборка: 20%, стратификация по class.
- Редкость odor: доля строго меньше 10% в обучающей выборке.
- Конвейер: RareOdorCounter → ColumnTransformer → LogisticRegression.
- Подбор C: [0.1, 1.0, 10.0], 5 фолдов, выбор по ROC-AUC.
- Дата запуска и окружение: **заполнить**.
- SHA-256 данных, размеры train/test и пропуски: **из run_metadata.json**.
- Редкие символы и их частоты: **из odor_frequencies.csv**.

## Метрики

| Показатель | Значение после запуска |
| --- | --- |
| Лучший C | заполнить из run_metadata.json |
| Средний ROC-AUC на CV | заполнить из run_metadata.json |
| Accuracy на test | заполнить из metrics.json |
| ROC-AUC на test | заполнить из metrics.json |
| F1 класса p на test | заполнить из metrics.json |
| Число ошибок | заполнить из metrics.json |

Прокомментируйте матрицу ошибок (порядок классов e, p), различие CV и test,
роль собственного признака и ограничения результата. Само наличие высокой
метрики не доказывает пользу счётчика: для этого нужен отдельный эксперимент
без него. Такой эксперимент в обязательные шаги лабораторной не входит.
