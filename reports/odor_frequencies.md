# Частоты кодов запаха Mushroom

Это подготовительный этап лабораторной работы № 1. Категории, которые
считаются редкими, пока не выбраны. Модель ещё не обучалась.

Источник: [Mushroom, OpenML ID 24, версия 1](https://www.openml.org/d/24).
Расшифровки кодов: [описание UCI](https://archive.ics.uci.edu/dataset/73/mushroom).

Данные содержат 8124 строки, 22 категориальных признака и целевую колонку
`class`: `e` — съедобный, `p` — ядовитый. Разбиение 80/20 выполнено с
`random_state=42` и `stratify=class`: 6499 строк train и 1625 строк test.
Частоты вычислены исключительно по train. В `odor` каждое значение —
однобуквенный код, поэтому число редких символов в одной строке будет
равно 0 или 1 после выбора множества редких кодов.

| Код | Запах | Количество в train | Доля в train |
| --- | --- | ---: | ---: |
| m | Затхлый | 27 | 0,42% |
| c | Креозотовый | 154 | 2,37% |
| p | Резкий | 194 | 2,99% |
| a | Миндальный | 318 | 4,89% |
| l | Анисовый | 319 | 4,91% |
| s | Пряный | 450 | 6,92% |
| y | Рыбный | 457 | 7,03% |
| f | Зловонный | 1754 | 26,99% |
| n | Без запаха | 2826 | 43,48% |

В исходном датасете есть 2480 пропусков в `stalk-root`. Условие ТЗ об
искусственном внесении пропусков применимо только к данным без пропусков,
поэтому для этого набора оно не требуется. Числовых исходных колонок нет;
числовая ветвь будущего ColumnTransformer обработает признак, добавленный
кастомным трансформером.

## Повторение расчёта

Команды выполняются из корня репозитория с Python 3.12:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m src.data.prepare
dvc status data/raw/mushroom.csv.dvc
```

Если локального CSV нет, скрипт скачивает фиксированную версию из OpenML.
Если файл уже существует, он используется без повторной загрузки.
Результат сохраняется в `reports/odor_frequencies.csv`.

DVC уже был инициализирован в исходном проекте. Его прежний указатель
`data/raw/minidataset.csv.dvc` сохранён: сам файл и DVC remote в исходном
репозитории отсутствуют. Поэтому приведённая команда проверяет именно
Mushroom. Команда `dvc status` без аргумента также проверит старый указатель
и в свежем клоне сообщит об отсутствии `minidataset.csv`.
